# jax-morph usage guides

These guides ship with jax-morph and describe the API version installed in the same environment.
Read one with `jax_morph.guides.guide(name)` and discover names with
`jax_morph.guides.list_guides()`.

- `basic-usage` - the smallest complete simulation.
- `concepts` - state synthesis, step types, execution order, and differentiation modes.
- `core-abstractions` - the primary objects and how they fit together.
- `extending` - the complete contract for implementing custom simulation steps.
- `serialization` - saving and loading models, states, and trajectories.
- `optimization/pathwise` - differentiating through reparameterized simulations.
- `optimization/reinforce` - score-function optimization for discrete stochastic events.
